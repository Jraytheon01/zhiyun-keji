# 智云课迹平台开发与联调说明 v1.0

## 1. 产品分工

- 录音与 ASR：课程入口，比赛 Demo 可使用模拟进度和手动转写。
- 智云课迹平台：课程知识本、可信状态账本、长期记忆、学习计划和证据展示。
- 平台 AI：课程复盘、整段对话分析、记忆候选提炼、档案问答和计划生成。
- TeleAgent：自然交互、课程工具调用和产物生成。
- 教育 Skill：规定课程依据、互动方式、结束语和回流动作。
- `zhiyun-learning` MCP：按手机号读取课程、检索跨课内容、读取学习上下文并回流完整对话。

## 2. 长期记忆结构

长期记忆不是一张“用户画像”表，而是三层状态：

1. 证据层：`learning_dialogue_turn` 保存关键原始对话；课程原文仍在 MySQL 主表。
2. 洞察与候选层：`dialogue_insight` 保存误区、理解、提问、自我纠正与待验证项；`learning_memory` 保存可复用的记忆候选。
3. 可信状态层：`mastery_state` 保存知识点状态、证据次数和最近理由；单次课程接触不等于掌握。

Milvus 集合为 `${MILVUS_COLLECTION_PREFIX}learning_memory`，保存：

- `vector_id`：由记忆 ID 确定性生成的 int64 主键；
- `learner_id`：检索时强制过滤；
- `embedding`：由记忆标题、知识点和内容生成；
- 其余完整内容与证据仍以 SQLite/MySQL 为准。

平台 AI 注入上下文时，先根据当前问题从 Milvus 召回 `vector_id`，再回 SQLite 读取完整记录，并与知识状态和最近学习事件一起组织提示词。向量命中本身不作为掌握证据。

## 3. TeleAgent 交互与回流

### 发起

平台创建 `teleagent_run`，生成 `run_id`，Receiver 将包含 `course_id`、`run_id`、任务类型和重点的提示词送入 TeleAgent。Receiver 记录真实 `session_id`，平台交接页展示该会话标识。

### 多轮互动

对课程复盘和学习检测，TeleAgent 首轮只读取课程依据、简短开场并提出一个问题。用户完成交流后发送：

> 结束复盘并回流课迹

Skill 随后调用 `complete_learning_interaction`，提交关键完整对话、摘要、初步判断和生成产物。

### 平台复核

平台根据 `run_id + phone + course_id + action` 校验归属和幂等性；平台 AI 再结合课程原文独立提炼，不接受 TeleAgent 直接修改长期画像。

## 4. 主要页面

- 首页：课程入口、课迹 AI 在线状态和下一步行动。
- 课程：多学习者课程记录、搜索与课程状态。
- 课程详情：NotebookLM 风格课程知识本、关键原文、知识关系与 TeleAgent 任务入口。
- TeleAgent 交接：四段链路、真实状态、会话标识和回流提示。
- 互动结果：整段对话洞察、提示程度、自我纠正、状态变化、记忆候选和下一步。
- 学习档案总览：课迹 AI、记忆问答、最近发现和证据闭环。
- 知识状态：可信状态账本。
- 成长轨迹：课程、互动、平台 AI 与计划事件。
- 学习计划：平台内生成、完成反思、后续再验证。
- 记忆档案：候选/有效状态、置信度、Milvus 索引状态和原始来源。

## 5. 关键接口

- `GET /api/health`：平台、AI、TeleAgent 和 Milvus 状态。
- `GET /api/bootstrap`：学习者、课程与能力。
- `POST /api/teleagent/runs`：创建 TeleAgent 学习任务。
- `GET /api/teleagent/runs/{run_id}`：刷新 Bridge 与会话状态。
- `POST /api/internal/learning-interactions`：教育 MCP 回流完整对话。
- `GET /api/internal/learning-context`：教育 MCP 获取长期学习上下文。
- `GET /api/growth`：学习档案数据。
- `POST /api/ai/archive-query`：基于档案与向量召回的课迹 AI 问答。

## 6. Demo 建议

演示时使用一条真实或模拟课程：

1. 导入转写并生成课程知识本；
2. 点击“带着这节课去 TeleAgent”；
3. TeleAgent 通过 `zhiyun-learning` 引用课程原文并提出一个问题；
4. 展示一次错误理解、提示和自我纠正；
5. 发送结束语触发回流；
6. 回到平台展示整段对话洞察、记忆候选和知识状态变化；
7. 在“问问课迹 AI”中询问最近仍需验证的内容；
8. 展示有依据的回答与下一步计划。

这条链路比单独展示摘要、思维导图或试卷更能体现平台价值。

## 7. 已知边界

- TeleAgent 当前没有经公开文档确认的“从外部直接切换到指定会话”API；Receiver 会创建/识别会话、聚焦窗口并把会话 ID 返回平台，但用户仍可能需要从 TeleAgent 左侧选择对应的“智云课迹”会话。
- 未配置企微通道时，TeleAgent 会在生成成功后报告外部投递失败；Receiver 已把“有生成内容的投递失败”视为本地生成成功，不再误报为模型失败。
- 比赛 Demo 不实现平台登录鉴权；数据仍按数据库用户与 MCP Key 映射的手机号隔离。
